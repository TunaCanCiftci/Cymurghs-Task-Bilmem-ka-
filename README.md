# FRC 2026 Everybot Code (Reference)

Bu repo, Cymurghs 7466 kapsamında verilen görev doğrultusunda eklenen 2026 Everybot referans kod tabanını içerir.

## Kaynak
- Referans alınan orijinal repo: `Robonauts-Everybot/FRC-Everybot-2026-Code`
- Dil / Altyapı: Java (WPILib)

## Proje Yapısı
- `src/main/java/frc/robot/`: Robot ana sınıfları, alt sistemler (`subsystems`), komutlar (`commands`) ve sabitler (`Constants.java`).
- `build.gradle` & `gradle/`: Gradle yapılandırması ve bağımlılıklar.

## Çalıştırma / İnceleme
1. Projeyi WPILib VS Code ile açın.
2. Gerekli Vendor Library'lerin kurulu olduğundan emin olun.
3. Kodun derlendiğini doğrulamak için `./gradlew build` komutunu çalıştırın.
